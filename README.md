
# Drone Control System

A custom PC-based drone ground-control application.

## Planned Technology

- Electron
- HTML, CSS and JavaScript
- Node.js
- Secure WebSocket communication
- WebRTC video streaming
- MAVLink
- ArduPilot SITL
- SQLite

## Development Roadmap

1. Development environment
2. Project structure
3. Electron desktop application
4. Drone registration and authentication
5. Simulated drone telemetry
6. Secure internet communication
7. Live video and GPS
8. Safety and failsafe testing
9. Hardware integration
